# Telewatch maintained fork

This repository continues the archived
[gohj99/Telewatch](https://github.com/gohj99/Telewatch) project. The upstream
author, gohj99, and all previous contributors retain copyright in their work.

The fork keeps the upstream history and source-code license. It adds watch UI,
sticker and emoji support, reading-position restoration, media-loading
improvements, performance work, and the NiagramX Cloudflare proxy integration.

The `libs/tcp2ws` component includes material derived from
[Niagram](https://github.com/HSSkyBoy/Niagram),
[Nullgram](https://github.com/qwq233/Nullgram),
[java-socks-proxy-server](https://github.com/bbottema/java-socks-proxy-server),
and [CF-Workers-TGProxy](https://github.com/ToiCF/CF-Workers-TGProxy). Its
license and notice files are kept alongside that component.

No Telegram API credentials, Cloudflare Worker secrets, signing keys, or local
build configuration are intentionally distributed with this repository.
